# Arqam Rashed / Portfolio 2026

A single-file portfolio for Arqam Rashed, full-stack architect and creative developer in Luxor, Egypt.

One persistent WebGL surface carries four acts:

1. **Core** - a displaced ferrofluid icosahedron in obsidian, titanium, and acid lime.
2. **Work** - a horizontal editorial track for three shipped systems, with WebGL project planes.
3. **System** - a GPU particle topology with selectable architecture clusters and glass HUD panels.
4. **Signal** - a gravitational portal, cursor-warped grid, and a direct contact line.

## Stack

- Three.js 0.187.0 and custom GLSL
- GSAP 3.15.1 with ScrollTrigger
- Lenis 1.3.27
- Archivo Black, Archivo, IBM Plex Mono, Instrument Serif

## Run

Open `index.html` in a modern browser. The page has no build step and no local dependencies. WebGL and CDN assets require a network connection.

Project media is embedded in the file, so the portfolio stays self-contained apart from the pinned CDN libraries and fonts.
